# 🛒 쇼핑 리스트

장보기 목록을 간단하게 관리하는 Streamlit 웹 앱입니다. 아이템 추가, 수정, 삭제, 체크 기능이 있습니다.

## 기능

- **추가**: 이름과 수량(1~999)을 입력해 추가합니다. Enter 키로도 추가됩니다.
- **수정**: ✏️ 버튼으로 이름과 수량을 바꿉니다.
- **삭제**: 🗑️ 버튼으로 항목을 지웁니다.
- **체크**: 체크박스로 구매 완료를 표시하며, 완료 항목은 취소선과 흐린 색으로 보입니다.
- **진행 현황**: "n / m 완료" 문구와 진행률 바를 보여 주고, 전부 체크하면 축하 메시지가 나옵니다.
- **완료 항목 삭제**: 체크된 항목을 한 번에 지웁니다.
- **자동 저장**: 변경할 때마다 `shopping_list.json`에 저장되어 앱을 다시 실행해도 목록이 유지됩니다.
- 밝은/어두운 테마와 모바일 화면을 지원합니다.

## 실행 방법

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `app.py` | 앱 본체 |
| `requirements.txt` | 의존성 (`streamlit`) |
| `shopping_list.json` | 목록 데이터. 첫 저장 때 자동으로 만들어지며 git에는 올리지 않습니다. |
| `PRD.md` | 제품 요구사항 문서 |
| `PROMPTS.md` | 단계별 개발 프롬프트 |
| `REVIEW.md` | PRD 준수 여부와 버그 검토 결과 |

## 배포 시 주의사항

Streamlit Community Cloud에 배포할 수 있지만 다음 두 가지를 알아두세요.

- **데이터가 영구적이지 않습니다.** 목록을 서버의 JSON 파일에 저장하므로, 앱이 재시작되거나 다시 배포되면 목록이 초기화될 수 있습니다.
- **모든 방문자가 같은 목록을 공유합니다.** 사용자 구분이 없어서 링크를 아는 사람은 누구나 목록을 보고 고칠 수 있습니다.

개인용이면 로컬 실행을 권장합니다. 배포해서 쓰려면 저장 부분(`app.py`의 `load_items()`, `write_items()`)을 Google Sheets나 DB 같은 외부 저장소로 바꿔야 합니다.
